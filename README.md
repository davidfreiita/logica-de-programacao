# 🚀 Minha Jornada na Lógica de Programação com JavaScript

Bem-vindo(a) ao meu repositório de estudos! Este espaço foi criado para guardar todos os meus códigos, exercícios e anotações enquanto aprendo a programar e a dominar a lógica de programação usando **JavaScript** e **Node.js**.

---

## 🛠️ O que estou utilizando?

Para construir meus programas e testar minhas ideias, meu ambiente foi configurado com:
* **Interpretador:** [Node.js](https://nodejs.org/) (para rodar o JavaScript direto no computador, sem precisar do navegador).
* **Editor de Código:** [Visual Studio Code (VS Code)](https://code.visualstudio.com/).
* **Executador de Código:** Extensão **Code Runner** (basta abrir um arquivo `.js` e clicar no botão de "Play" no canto superior direito para rodar).

---

## 🧭 Guia Rápido de Atalhos

Para me ajudar durante o dia a dia, meu VS Code foi personalizado pelo meu mentor para facilitar minha vida:
* **Salvar Código:** Não preciso me preocupar com `Ctrl + S` o tempo todo! O VS Code salva meu código sozinho 1 segundo após eu parar de digitar.
* **Organização (Tab):** Cada vez que aperto a tecla `Tab`, ele adiciona exatamente **4 espaços** para deixar meu código bem estruturado (indentado).
* **Executar o Código:** Uso o atalho `Ctrl + Alt + N` (ou clico no botão de play no topo do VS Code) para rodar meu programa no terminal.

---

## 💡 Dicas Importantes que meu Mentor me deu:

1. **Errar faz parte:** Se o código der erro (aquelas letrinhas vermelhas no terminal), não se desespere! Leia a mensagem de erro com calma; ela geralmente diz exatamente em qual linha o problema está.
2. **Escreva comentários:** Use `//` para explicar para você mesmo o que o seu código está fazendo. Isso ajuda muito a fixar a lógica na mente.
3. **Pratique todo dia:** Escrever 15 minutos de código todos os dias é muito melhor do que estudar 3 horas apenas uma vez na semana!
